## 一、功能范围

本应用需要您提供本人账号，代您访问学校各业务系统的公开接口，并在您的设备上展示结果，主要包括：

1. 课表管理、桌面小组件、课前提醒等；
2. 教务信息查询：成绩、考试安排、教学评价、学习中心等；
3. 生活服务查询：宿舍电费、一卡通余额与消费记录等；
4. 校园网服务：宽带运营商绑定、校园网自助服务与在线设备管理等；
5. 报修、校历、图书借阅、常见问题等辅助功能。

以上均为非官方实现，可能因学校系统调整而随时失效或出现数据差异。

## 二、账号与凭据

1. 为访问上述系统，您需要输入学号与密码。密码通过系统级安全存储（Android Keystore / iOS Keychain）加密保存在本机，不会由本应用上传至开发者自建服务器。
2. 登录及数据请求会直接发送至学校对应系统，其处理方式以学校规定为准，与本应用无关。
3. 是否记住密码由您选择，您可随时在应用内清除本地凭据。请勿在非本人设备上保存密码。
4. 宽带绑定、报修等操作所需的账号、密码、图片等信息，会按对应系统的要求直接提交至该系统。

## 三、数据与隐私

1. 本应用不收集与功能无关的个人信息，不读取通讯录、短信，仅在您主动选择时读取相册图片（用于设置课表背景或提交报修）。
2. 课表、个性化设置等数据默认仅保存在本机；您主动生成或导入的「分享码」会将相关配置经由项目服务中转，请自行确认分享对象与范围。
3. 为实现远程配置、版本更新、校历下发与故障排查，本应用会向项目服务发送匿名统计与故障信息，仅用于维护与改进应用，不包含账号密码。
4. 请勿使用本应用处理他人账号或未经授权的数据。

## 1、登录所使用的账户密码是什么？

> 即**徐州工程学院统一身份认证**的账号密码（与校园 Wi-Fi 认证相同）。初始密码为**身份证号后 6 位**，字母大写。核对账号：[ca.xzit.edu.cn/cas/login](https://ca.xzit.edu.cn/cas/login)

## 2、如何更换绑定的手机号？

> **学生**：企业微信 App → 我 → 设置 → 账号 → 手机号 → 更换手机号。**教职工**：联系信息化中心教学资源科，电话 0516-83105370。

## 3、为什么提示 “The request connection took longer than expected…”？

> 网络到校园网的连接质量不佳。请切换到**校园网**后重试；移动数据下连通性大致为 电信 ＞ 联通 ＞ 移动。

## 4、遇到异常情况怎么办？

> 先更新到**最新版本**重试；仍异常请到 GitHub 提 issue 或联系开发者，附上描述与截图。本应用为非官方应用，请勿就本应用的问题联系校方。
